# JavaScriptFundamentos03

continuação dos estudos de JavaScript com foco em funções, métodos de arrey, objetos ,JSON e introdução à Programação Orientada a Objetos.

## Objetivos

Ao final deste projeto, o aluno deverá ser capaz de:

- criar e ultilizar funções
- Trabalhar com parâmetros, argumentos e retornos;
- Ultilizar Arrow Functions;
- Criar e manipular objetos;
- Trabalhar com array de objetos
- Entender o uso de `this`
- Converter objetos para JSON e JSON objetos;
- Criar classe;
- Ultilizar `construtor`;
- Instanciar objetos com `new`;
- Criar atributos e métodos;
- Compreender os conceitos iniciais de encapsulamento, herança e polimorfismo;

## Como executar

Abra o terminal na pasta e execute: 

```
bash
 node nome-do-arquivo.js
```
